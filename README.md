# CantorsProof

Технологический 🎬 Визуализация доказательства Кантора на Python (Manim)
Репозиторий содержит скрипт для генерации математической анимации, которая наглядно демонстрирует диагональный метод Кантора для доказательства несчётности множества точек на отрезке
.
Анимация создана с помощью библиотеки процедурной графики Manim.
📌 Описание проекта
Проект визуализирует классическое математическое доказательство от противного:
    Предположение: все точки отрезка
    можно пересчитать и выписать в список.
    Процесс: строится новое число
    , цифры которого отличаются от диагональных цифр чисел в списке.
    Результат: новое число
    гарантированно лежит на отрезке, но отсутствует в исходном списке. Камера приближает точку
    , показывая её уникальность.

🛠 Стек технологий

    Python 3.x — основной язык разработки.
    Manim — библиотека для создания точных математических анимаций.
